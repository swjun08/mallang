# 말랑 — 댓글을 말랑하게

유튜브 댓글의 의견은 남기고, 공격적인 표현만 걷어내 보여 주는 크롬 확장.
디지털새싹 문제해결 경진대회 2026 C.O.D.E. 트랙3 — 팀 말랑(박서준·백준오·서재호, 담당 문서연 선생님).

## 설치(개발용)
1. 크롬 주소창에 `chrome://extensions` → 오른쪽 위 **개발자 모드** 켜기
2. **압축해제된 확장 프로그램을 로드합니다** → 이 폴더(`mallang`) 선택
3. 툴바의 말랑 아이콘 → **Claude API 키** 붙여 넣기(선생님 명의, 시연용). 키가 없어도 욕설 사전으로 가리기는 동작한다.

## 동작
- 화면에 들어오기 직전의 댓글만 읽는다(IntersectionObserver). 안 본 댓글은 보내지 않는다.
  댓글이 오른쪽 패널(자체 스크롤 상자)에 뜨는 레이아웃에서도 그 상자를 기준으로 한 장 앞까지 미리 읽는다.
- 읽는 동안: 원문을 흐리게 하고 시간 옆에 「읽는 중」, 댓글창 머리에 "댓글 N개를 말랑이 읽고 있어요".
- 욕설 사전(`src/dict.js`)에 걸리면 즉시 가리고, 20개씩 묶어 Claude에 보내 유형·강도·근거·순화문을 받는다.
- 강도(약/보통/강)는 기준선만 바꾼다 → API를 다시 부르지 않는다.
- 순화문에 욕이 남았거나 의견이 없는 댓글이면 순화 대신 가린다(블러 + 보기).
- 답글 코치: 입력창에서 1.2초 멈추면 검사하고 바꿔 쓸 문장을 제안한다. 전송은 막지 않는다.
- 저장하는 것: 설정, 오늘 집계, "문제없어요" 목록(원문이 아닌 지문). 순화 결과는 저장하지 않는다.
- AI가 실패하면 숨기지 않는다: 댓글창 머리에 "AI 연결에 문제가 있어 욕설만 가리고 있어요", 팝업에 이유(키 오류·크레딧 부족 등).
  키 오류·크레딧 부족이면 키를 바꿀 때까지 다시 부르지 않고, 그 밖의 실패는 30초 쉰다.
- 팝업: 오늘 AI를 몇 번 썼는지와 어림 비용(응답의 토큰 수 × 가격표). 남은 크레딧은 일반 키로 조회할 수 없어 Console 링크로 대신한다.
- 키 저장 전 형식 검사(sk-ant-api…, 공백·따옴표 제거, 로그인 토큰·관리자 키 거절). 저장된 키는 끝 4자리만 보여 준다.

## 주의
- 확장을 새로고침(chrome://extensions의 ↻)하면 이미 열려 있던 유튜브 탭은 옛 스크립트가 손을 떼고 원래 화면으로 돌아간다. 탭을 새로고침해야 새 버전이 붙는다.

## 파일
| 파일 | 하는 일 |
|---|---|
| `src/filter.js` | 우회 표기 정규화(초성·자모 분리·띄어쓰기·반복·전각) + 사전 대조 |
| `src/dict.js` | 욕설 사전 — 서재호 담당, 데이터셋으로 키운다 |
| `src/background.js` | Claude API 호출(모델·프롬프트·스키마). 엔진을 바꾸면 `judge()`만 갈아끼운다 |
| `src/content.js` / `content.css` | 댓글 감지·판단·그리기(칩, 원문 카드, 가림, 댓글창 상태 줄) |
| `src/coach.js` | 답글 코치 |
| `popup/` | 켜기·강도·오늘 리포트·API 키 |
| `design/` | 마스코트 원본과 화면 목업 |
